# AgriShield Expert Validation & Verification Protocol

## 1. Important Validation Status Notice

---

## 2. Validation Framework & Concepts

To maintain rigorous scientific standards and eliminate self-labeling bias, AgriShield strictly separates four distinct data concepts across system interfaces and databases:

1. **Dataset Label (`disease_label`)**: The initial ground-truth disease class assigned by dataset curators for supervised ML training.
2. **Model Prediction (`model_prediction`)**: The statistical prediction output and confidence score generated by the ML screening classifier.
3. **Expert Validation (`expert_validation_status`)**: Independent diagnostic decision (`Confirmed`, `Corrected`, `Uncertain`) submitted by a certified agricultural pathologist.
4. **Demo / Seed Validation (`DEMO_SEED`)**: Demonstration workflow records used exclusively for evaluating UI/UX escalation flows during prototype reviews.

---

## 3. Expert Validation Protocol & Role Requirements

### Validator Qualification Criteria
- Minimum Bachelor of Science (B.Sc.) in Agriculture, Plant Pathology, or Agronomy.
- Demonstrated field experience in diagnosing crop foliar diseases across Tamil Nadu or regional procurement districts.

### Standard Operating Procedure (SOP)
1. **Queue Inspection**: Pathologist opens `/expert` queue and views full-resolution crop photo alongside metadata (crop type, symptoms, growth stage, region).
2. **Independent Assessment**: Pathologist inspects leaf lesion geometry, discoloration patterns, and fungal pustules **without** relying solely on the ML screening prediction.
3. **Decision Recording**: Pathologist selects diagnostic decision (`Validated (Confirmed)`, `Not Confirmed / Corrected`, `Needs More Information / Uncertain`) and enters advisory comments.
4. **Database Persistence**: System records `expert_user_id`, `review_timestamp`, and computes `useful_review_time_seconds`.

---

## 4. Structured Validation Record Schema

| Field Name | Description | Allowed Values / Format |
|---|---|---|
| `validation_id` | Unique review identifier | Integer Primary Key |
| `image_id` | Foreign key to observation / dataset image | String / Integer |
| `validator_role` | Certified role title | `Senior Agronomist`, `Plant Pathologist` |
| `expert_validation_status` | Status classification | `NOT_VALIDATED`, `PENDING_VALIDATION`, `EXPERT_VALIDATED`, `DEMO_SEED` |
| `validated_label` | Confirmed/corrected disease class | Standard 17 crop-disease classes |
| `comments` | Agronomic advisory notes | Freeform text |
| `validation_date` | Date and time of expert review | ISO 8601 timestamp |

---

## 5. Distinction Between Demo Workflow & Independent Evidence

- **Demo Workflow (`DEMO_SEED`)**: Enables evaluators to test the interactive expert review portal (`/expert`), review drawer, and timestamp SLA calculations using pre-populated sample records.
- **Independent Validation Evidence**: Requires field validation by accredited agricultural research institutes (*e.g., TNAU / ICAR*). Independent expert validation is explicitly marked **PENDING** until formal field trials commence.
